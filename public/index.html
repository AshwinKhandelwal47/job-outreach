⚙️ How to configure your Gmail App Password
  1. Open your Google Account and turn on 2-Step Verification if not already enabled.
  2. Navigate to Google App Passwords.
  3. Enter an app name like JobSearchMailer and click Create.
  4. Copy the 16-character password provided by Google.
  5. Open the .env file in this project folder and enter: 
    GMAIL_USER=your-actual-email@gmail.com
GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
PORT=3000
  6. Restart the server (or it will auto-detect next time you send).
